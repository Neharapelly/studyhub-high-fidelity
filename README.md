# StudyHub - High Fidelity UI Design

StudyHub is a high-fidelity learning platform UI design created for CodeAlpha Task 2.

## Features

- Modern learning platform interface
- User-friendly dashboard
- Course browsing interface
- Responsive UI design
- Clean typography and visual design

## Technologies Used

- HTML5
- CSS3

## Live Demo

https://Neharapelly.github.io/studyhub-high-fidelity/

## Project Purpose

This project converts the StudyHub low-fidelity wireframe into a high-fidelity UI design with colors, typography, buttons, icons, and visual styling.
